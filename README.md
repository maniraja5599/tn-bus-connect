# TN BusConnect — Unified 38-District Tamil Nadu Bus Timings Prototype

A daylight-readable, civic-tech mobile web prototype unifying Tamil Nadu's **8 state transport corporations** (MTC, SETC, and 6 TNSTC divisions) into one commuter-first interface.

- **Live Demo:** https://tn-bus-connect.netlify.app
- **Flow:** District → From → To → 1-tap Reverse (`⇅`)
- **Features:**
  - Time-first departure cards (Official timetables, OTRS/PNR tracking, and general frequencies)
  - `Vetri Payanam ₹0` women's free bus filter
  - QR-ready Stand Departure Boards (`#stand=namakkal`, `#stand=salem`, `#stand=trichy`, `#stand=chennai`, `#stand=tirunelveli`)
  - 2.4 MB Offline District Pack concept for zero-signal rural & ghat routes (Kolli Hills, Yercaud Rt 1165, Ooty 14 Bends)

Proposed by **Mani Raja** ([@manirajannm](https://x.com/manirajannm)) — Open GTFS + GTFS-RT civic transit initiative.
